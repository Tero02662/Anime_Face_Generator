# Anime_Face_Generator
Js generator anime faces 64*64
Dataset: https://www.kaggle.com/datasets/splcher/animefacedataset
Original code: https://docs.pytorch.org/tutorials/beginner/dcgan_faces_tutorial.html

To use:
git clone [https://github.com/Tero02662/Anime_Face_Generator.git](https://github.com/Tero02662/Anime_Face_Generator.git)
cd Anime_Face_Generator
pip install -r requirements.txt

install dataset
fill the py.yml file
launch train.py

To get photos generated by the neural network run try.py
